# 槓桿互動教具

手機、平板優先的靜態互動網頁。以本機靜態伺服器開啟 index.html，或發布至 GitHub Pages，無需建置與外部套件。

- 力臂與力矩：拖曳箭頭轉向、拖曳槓桿上的圓點移動施力點、直桿支點移位；按展示顯示垂直力臂與力矩。
- 槓桿與砝碼：20 個 20 g 砝碼，逐顆拖曳串聯吊掛，拖曳時預示吸附刻度與掛放位置，放開才移位，可單顆移除，自由探索平衡。
- 擺動採阻尼示意模型；失衡時停止角度不代表靜力平衡。忽略摩擦與槓桿自重。

執行測試：`node --test`。本機預覽：`python -m http.server 8080`。

教材 PDF 不包含在發布內容內。
